## Evaluation of the coder's choices
1. Whitespace-only `from`/`to` (e.g. `" "`) returns 422, not absent. **Accepted.** Spec Q15 says only that an *empty* value counts as not supplied. The ADR contract (line 116) lists whitespace-only explicitly for `category` only. Sequence step 2 ("Map empty or whitespace-only values to `None`") is looser, so the ADR is internally inconsistent here. Treating `" "` as a malformed date follows the more specific contract text and the strict date rule. See the nit below about recording this.
2. Repeated `category` returns 422 even when the values are equal or empty. **Accepted.** Q15 says "A repeated `category` returns 422" without exceptions, and the ADR does the repeated check before mapping empty values. It is tested.
3. Literal `422` instead of a `status.*` constant. **Accepted.** `app/errors.py` uses literal 422 throughout. Starlette also renamed `HTTP_422_UNPROCESSABLE_ENTITY`, so the literal avoids a deprecation trap.
