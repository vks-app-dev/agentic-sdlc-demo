## Coder decisions evaluated
- HostEnvelopeMiddleware (TrustedHost rejection rewritten into a Q10 400 `bad_request` envelope, "Invalid host header", host not echoed): agreed. ADR line 21 / Q10 require one shape for every 4xx, and Starlette's plain-text 400 would break that. The host check itself is still delegated to Starlette's `TrustedHostMiddleware` with `www_redirect=False`, so no host-matching logic was reimplemented. Responses from the wrapped app pass through unchanged once the request is accepted. On rejection the plain-text response is swallowed and the envelope is sent. Exceptions raised after acceptance still reach CatchAll. Non-HTTP scopes (lifespan) pass through. Tests cover suffix/prefix tricks (`localhost.evil.example`, `127.0.0.1.nip.io`, `www.localhost`), `0.0.0.0`, LAN IPs, an empty Host and an uppercase LOCALHOST.
- Mount order CatchAll -> HostEnvelope -> BodySizeLimit -> router: correct. It matches the T4 review and the ADR: a foreign Host is rejected before any body is read (tested with an oversized body plus a foreign Host, which gives 400), and CatchAll is outermost (asserted through `app.user_middleware`).
- README `uv run --with uvicorn`: acceptable, since uvicorn is not a dependency (see nit). The command binds 127.0.0.1, uses `--workers 1` and `--no-access-log`, and the no-exposure-until-auth note covers 0.0.0.0, container ports, reverse proxies/tunnels, CORS, ALLOWED_HOSTS, rate limiting and pagination.
- CORS preflight test (`OPTIONS /expenses` -> 405 envelope): it stays valid after T7. Starlette `Route`s with methods {GET, HEAD, POST} answer OPTIONS with 405 when no CORSMiddleware is present. The test asserts that no `access-control-allow-origin` header is sent.
